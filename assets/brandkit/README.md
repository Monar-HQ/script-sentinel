# ScriptSentinel identity assets

The production identity uses a geometric S monogram, a compact wordmark and
technical diagrams. Copy describes the product and its controls directly.
Do not add slogans, simulated threat counters, testimonials or certification marks.

## Files

- `mark.svg`: the editable 32-unit monogram used by the local console.
- `identity-system.svg`: logo geometry, exact color values, typography and applications.
- `../hero-v1.svg`: the repository header and source for the social preview.
- `../social-preview.png`: the ready-to-upload GitHub share card (1200 × 630).
- `../social-preview.svg`: its editable vector source.
- `../console-v1.png` and `../evidence-v1.png`: captures of the running application.

Graphite #101110 and off-white #f1f3e9 carry the interface. Signal yellow #dffc70
is reserved for actions, identifiers and selected states. System sans and
monospace fonts keep the application independent of external asset services.
Use the SVG masters for resizing; keep their view boxes and aspect ratios.

An earlier concept board used the built-in image-generation tool during the
requested brandkit exploration. It was retired from the current asset set after
design review. The current reference is an editable vector specification;
product screenshots are reproduced with `packaging/preview_console.py`.
